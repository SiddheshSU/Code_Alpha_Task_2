# 🤖 StudentGPT – Animated FAQ Chatbot

## 📌 Project Overview

StudentGPT is an animated and interactive College FAQ Chatbot developed using Python and Streamlit.

The chatbot uses Natural Language Processing (NLP) techniques to understand user questions and find the most relevant answer from a predefined collection of frequently asked questions.

The project uses **TF-IDF Vectorization** and **Cosine Similarity** to compare the user's question with the available FAQ questions.

This project was developed as part of the **CodeAlpha Task 2 – Chatbot for FAQs**.
